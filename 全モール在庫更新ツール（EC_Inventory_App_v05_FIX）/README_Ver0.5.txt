EC在庫更新アプリ Ver0.5

Ver0.4を安定版として残し、以下を追加したバージョンです。

【Ver0.5追加機能】
・欠品履歴を自動保存
・新規欠品：前回在庫1以上 → 今回0
・継続欠品：前回0 → 今回0
・欠品解消：前回0 → 今回1以上
・初回実行時の在庫0は「初回欠品」
・Web6桁商品と販売SKUの両方で欠品状況を出力
・7桁見積り商品構成マスターに対応
・見積り7桁の在庫＝構成各Webコードの「販売可能在庫÷必要数量」の最小値
・見積り構成未登録は自動更新せず保留

【見積り構成マスター】
同梱の estimate_composition_master_template.csv をExcelで編集できます。

必須列：
見積り番号 / Webコード / 必要数量

任意列：
見積り商品名 / 有効 / 備考

例：
1234567,見積セットA,111111,2,1,
1234567,見積セットA,222222,1,1,
1234567,見積セットA,333333,3,1,

【欠品履歴の保存場所】
出力先フォルダ内の _system/inventory_state.json に保存します。
このファイルを消すと、次回は再び「初回判定」になります。

【欠品出力】
・欠品商品_YYYYMMDD.csv
  Web6桁・見積り7桁を商品単位で表示
・販売SKU欠品_YYYYMMDD.csv
  Amazon / メルカリ / itemRobot の販売SKU単位で表示

欠品リストは
1. 新規欠品
2. 欠品解消
3. 継続欠品
4. 初回欠品
の優先順で並びます。

【従来の在庫計算】
販売可能在庫 ＝ 卸会社の調整在庫 + LOGILESSのフリー在庫

SKUルール：
123456 → そのまま
123456x5 → 在庫÷5 切り捨て
123456mx1 / xm1 → 在庫÷1
123456d3 / 123456/3 → 在庫×3
123456-1 → 123456をWebコードとして使用
7桁数字 → 見積り構成マスターを参照

【起動】
初回のみ 01_SETUP.bat
普段は 02_START.bat
