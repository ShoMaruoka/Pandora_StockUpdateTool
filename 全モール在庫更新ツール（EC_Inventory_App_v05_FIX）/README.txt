EC在庫更新アプリ Ver0.4（操作確認版）

【今回の追加】
・3ステップ画面（ファイル選択 → データチェック → 更新ファイル作成）
・入力ファイルの必須列チェック
・モール別のOK / 保留件数表示
・旧在庫から80%以上減るSKUを「急減警告」として表示
・実行ごとに日時付きフォルダを作成し、前回出力を上書きしない
・要確認SKUだけを抽出したCSVを追加
・ir-itemsubを利用したir-itemのシステムSKU照合

【販売可能在庫】
卸会社 最新YYYYMMDDシートの調整在庫（M列）
＋ LOGILESS フリー在庫

【SKUルール】
123456       → 在庫そのまま
123456x5     → 在庫÷5（切り捨て）
123456mx1    → 在庫÷1
123456xm1    → 在庫÷1
123456d3     → 在庫×3
123456/3     → 在庫×3
123456-1     → WebCD 123456として在庫そのまま
1234567      → 7桁見積りコード。自動更新しない

【itemRobot】
選択項目あり：
ir-selection「楽天　システム連携用SKU番号」→ WebCD

選択項目なし：
ir-item「商品コード（楽天URL）」
→ ir-itemsub「メインデータの商品コード（楽天URL）」
→ ir-itemsub「システム連携用SKU番号」
→ WebCD

itemsubにない場合だけ、ir-itemの商品コードが6桁WebCDとして直接一致する場合に更新します。

【使い方】
1. 初回のみ「初回セットアップ.bat」
2. 「EC在庫更新アプリを起動.bat」
3. 8ファイルを選択
4. データチェック
5. 保留・急減警告を確認
6. 更新ファイル作成

※ Pythonが未導入の場合はPython 3.11以降をインストールしてください。
※ 最終的にはWindows上で「EXE作成.bat」を実行すると dist\EC在庫更新.exe を作れます。
