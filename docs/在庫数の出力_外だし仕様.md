## 1. 概要

指定した Excel（`.xls`）の A 列にある商品コードについて、倉庫別の引当後在庫と商品情報を同じファイルへ書き戻す。

- 読み取りはビュー `dbo.VO0507在庫出力` への SELECT のみである。
- ストアドプロシージャは呼ばない。
- `T810在庫` を含む業務テーブルは更新しない。
- 出力先はアップロード用の新規ファイルではなく、選択したブックの上書きである。

---

## 2. 現行システムの起動条件

メニュー文言は「在庫数の出力(&Z)」。画面クラスは `prjStock.frmGoodsImportWrite`。MDI 子として1つだけ開く。

メニューが表示されるのは、ログイン拠点 `SectionCD = 210` のときだけである。それ以外ではメニュー自体が非表示になる。この判定は出力処理の中には無い。別システムの利用者制限は、移設先の認証に任せてよい。

画面タイトル（フォーム `Tag`）は「CSV商品の在庫書出」。案内ラベルは「EXCELで取り込んだ商品の在庫数の出力->A列の2番目から商品CDを指定」。

操作は次の3つだけである。

| 操作 | 処理 |
|------|------|
| 参照 | ファイル選択。初期フォルダ `C:\`。フィルタは `xlsファイル\|*.xls` |
| (F5) 取込開始 | 検証して在庫を書き、同じパスへ保存 |
| (F12) 終了 | 画面を閉じる |

ファイル名欄は手入力不可（参照でのみセット）。

---

## 3. Excel 契約

対象は先頭シート（インデックス 0）のみ。2枚目以降は見ない。

行番号は Excel の表示行（1始まり）。実装上の行インデックスは 0 始まりで、データ開始はインデックス 1（表示上の2行目）である。

| 列 | 1行目（処理後に書くヘッダ） | 2行目以降 | 方向 |
|----|------------------------------|-----------|------|
| A | 処理前から商品コードが入っている想定。ヘッダは上書きしない | 商品CD（JAN） | 入力 |
| B | `WebCD` | WebCD | 出力 |
| C | `商品名` | 商品名 | 出力 |
| D | `規格` | 規格 | 出力 |
| E | `仕入先CD` | 仕入先CD | 出力 |
| F | `仕入先名` | 仕入先略称 | 出力 |
| G | `在庫横浜` | 倉庫 120 | 出力 |
| H | `在庫八尾` | 倉庫 400 | 出力 |
| I | `在庫八尾2` | 倉庫 405 | 出力 |
| J | `在庫西` | 倉庫 110 | 出力 |
| K | `在庫東` | 倉庫 150 | 出力 |
| L | `在庫福岡` | 倉庫 180 | 出力 |

ヘッダ文字列は上表のとおり固定である。ビューの SELECT 列順とは一致しない。ビューは `在庫福岡` を `在庫西` より前に持ち、`WebCD` は末尾にある。Excel へ書くときは上表の列位置に並べ替える。

A列以外の既存値は、その行が「書込対象」になったときだけ B〜L を上書きする。書込対象にならない行は触らない。

---

## 4. 行の読み方と判定

2行目から下へ進む。A列の値が空（長さ 0）の行で終了する。空行より下は処理しない。

各行の判定は次の順である。

1. 文字列化した A列の長さが 13 でない → エラー。その行は書かない。
2. 半角英数字（`^[a-zA-Z0-9]+$`）でない → エラー。その行は書かない。
3. 上記を満たす → 大文字化して商品CDとする。ビューを1件検索する。
4. ビューに行がある → B〜L へ書く。
5. ビューに行が無い → エラーにはしない。B〜L は空のまま（既存値も消さない）。

エラー行でもループは続行する。

画面カウンタ:

| 表示 | 意味 |
|------|------|
| 取込件数 | 空行の手前まで読んだ行数。エラー行を含む |
| エラー件数 | 桁数または文字種で落ちた行数。ビュー未ヒットは含まない |

---

## 5. 保存とメッセージ

| 状況 | ファイル | メッセージ |
|------|----------|------------|
| ファイル名が空 | なし | 「ファイルが指定されていません！」（タイトル: 実行確認） |
| パスにファイルが無い | なし | 完了メッセージは出さない |
| ブックを開けない | 保存しない | 例外メッセージ（タイトル: エラー発生）。完了メッセージは出さない |
| 正常な商品CDが1件以上 | 1行目ヘッダを書いて同じパスへ上書き | 「取込が完了しました！」（タイトル: 正常終了） |
| 読んだ行がすべてエラー、またはデータ行が無い | 保存しない | ブックを開けていれば「取込が完了しました！」 |
| 処理中の例外 | 保存まで到達していなければ未保存 | 例外メッセージ（タイトル: エラー発生） |

正常な商品CDが1件でもあれば、ビュー未ヒットだけで B〜L が空でも保存する。ヘッダを書く条件は「検証を通過した商品CDが1件以上」であり、「在庫行がヒットした」ではない。

処理中は待ちカーソルにする。

## 6. データ取得

商品1件につき次と同等の参照を行う。現行は条件を文字列連結している。別システムではパラメータ化する。商品CDは検証済みの13桁英数字（大文字）だけを渡す。

```sql
SELECT *
FROM dbo.VO0507在庫出力
WHERE 商品CD = @商品CD;
```

結果が複数行になる定義ではない。先頭行だけを使う（現行は `Rows(0)`）。

### 6.1 ビュー定義（現行）

```sql
ALTER VIEW [dbo].[VO0507在庫出力]
AS
SELECT 商品CD, 商品名, 規格, 仕入先CD, 仕入先名,
       SUM(CASE WHEN 倉庫CD = 120 THEN 在庫数 ELSE 0 END) AS 在庫横浜,
       SUM(CASE WHEN 倉庫CD = 400 THEN 在庫数 ELSE 0 END) AS 在庫八尾,
       SUM(CASE WHEN 倉庫CD = 405 THEN 在庫数 ELSE 0 END) AS 在庫八尾2,
       SUM(CASE WHEN 倉庫CD = 180 THEN 在庫数 ELSE 0 END) AS 在庫福岡,
       SUM(CASE WHEN 倉庫CD = 110 THEN 在庫数 ELSE 0 END) AS 在庫西,
       SUM(CASE WHEN 倉庫CD = 150 THEN 在庫数 ELSE 0 END) AS 在庫東,
       WebCD
FROM (
    SELECT dbo.T810在庫.倉庫CD,
           dbo.T410商品.仕入先CD,
           dbo.Get会社名略作成(dbo.T430仕入先.仕入先名) AS 仕入先名,
           dbo.T810在庫.商品CD,
           dbo.T410商品.商品名,
           dbo.T410商品.規格,
           dbo.T410商品.WebCD,
           dbo.T810在庫.在庫数 - dbo.T810在庫.在庫引当数 AS 在庫数
    FROM dbo.T810在庫
    INNER JOIN dbo.T410商品
        ON dbo.T810在庫.商品CD = dbo.T410商品.商品CD
    LEFT OUTER JOIN dbo.T430仕入先
        ON dbo.T410商品.仕入先CD = dbo.T430仕入先.仕入先CD
    WHERE dbo.T810在庫.倉庫CD IN (120, 180, 400, 110, 405, 150, 180)
) AS A
GROUP BY 商品CD, 商品名, 規格, 仕入先CD, 仕入先名, WebCD;
```

`IN` 句の `180` は重複している。結果は1回分と同じである。

### 6.2 在庫数の意味

各倉庫列は `T810在庫.在庫数 - T810在庫.在庫引当数` である。

- 引当可能数ではない。
- 実在庫数ではない。
- 発注残は含まない。

対象倉庫に `T810` 行が無い商品は、商品マスタにあってもビューに出ない。Excel の B〜L は空欄のままになる。行がある倉庫は 0 も数値として出る。対象外倉庫（北海道 190、沖縄 440 など）は列が無く、合計にも入らない。

| 倉庫CD | Excel列名 | 商品マスタ側の呼び方（参考） |
|--------|-----------|------------------------------|
| 120 | 在庫横浜 | 横浜 |
| 400 | 在庫八尾 | 大阪① |
| 405 | 在庫八尾2 | 大阪② |
| 110 | 在庫西 | 西日本 |
| 150 | 在庫東 | 東日本 |
| 180 | 在庫福岡 | 福岡 |

### 6.3 結合

| テーブル | 結合 | 効き方 |
|----------|------|--------|
| `T810在庫` | 起点 | 対象6倉庫の行だけ |
| `T410商品` | INNER JOIN | 商品マスタが無い在庫行は出ない |
| `T430仕入先` | LEFT JOIN | 仕入先が無くても商品行は出る。仕入先名は NULL になり得る |

仕入先名は `dbo.Get会社名略作成` の戻り値である。関数の実処理は次の置換（上から順）である。入力 NULL はそのまま NULL になる。

| 検索 | 置換 |
|------|------|
| `株式会社 `（末尾スペース） | `(株)` |
| ` 株式会社`（先頭スペース） | `(株)` |
| `株式会社` | `(株)` |
| `（株）` | `(株)` |
| `有限会社 `（末尾スペース） | `(有)` |
| ` 有限会社`（先頭スペース） | `(有)` |
| `（有）` | `(有)` |
| ` 合同会社`（先頭スペース付きのみ） | `(合)` |

先頭スペースの無い「合同会社」は置換しない。別システムが同じデータベースのビューを SELECT するなら、この関数を再実装しなくてよい。

## 7. 別システムでの実現条件

必須:

1. `.xls` の先頭シートを読み、A列2行目から空行まで処理する。
2. 13桁・半角英数字以外をエラーにする。通過したコードは大文字で検索する。
3. 在庫は `在庫数 - 在庫引当数` を、倉庫 120 / 400 / 405 / 110 / 150 / 180 の列へ出す。
4. ビュー未ヒットはエラーにせず、その行の B〜L を書き換えない。
5. 検証通過が1件以上のときだけ、1行目ヘッダを書いて同じファイルを上書きする。
6. 業務テーブルへ INSERT / UPDATE / DELETE しない。ストアドは呼ばない。

任意（現行画面の再現）:

- 取込件数・エラー件数の表示
- 本書第5節のメッセージ文言

やらないこと:

- 在庫数の手修正（別機能 `SO0501在庫数設定`）
- 棚卸の実在庫更新（別機能 `SO0502実在庫数設定`）
- 全商品の一括出力（入力ファイルに無い商品は出さない）

---

## 8. 確認用 SQL

```sql
SELECT 商品CD, WebCD, 商品名, 規格, 仕入先CD, 仕入先名,
       在庫横浜, 在庫八尾, 在庫八尾2, 在庫西, 在庫東, 在庫福岡
FROM dbo.VO0507在庫出力
WHERE 商品CD = @商品CD;

SELECT 倉庫CD, 在庫数, 在庫引当数,
       在庫数 - 在庫引当数 AS 出力値
FROM dbo.T810在庫
WHERE 商品CD = @商品CD
  AND 倉庫CD IN (120, 110, 150, 180, 400, 405);
```

突合せの期待:

- ビューの各倉庫列と、2本目の `出力値` が一致する。
- `T810` が0件ならビューも0件で、Excel の B〜L は空のまま。
- 仕入先が無い商品は仕入先名 NULL。Excel には空として書いてよい。
