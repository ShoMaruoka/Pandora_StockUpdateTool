# 夜間在庫更新の実行手順

記録日: 2026-10-13  
更新日: 2026-10-13（認証フォルダは tools/settings.json の EC_INVENTORY_DIR）

この文書は `MARUOKA-PC` への登録の記録である。サーバーへ移すときは `docs/夜間在庫更新_サーバー導入手順.md` に従う。

この手順で登録するのは、Amazon へ数量を送らない `--dry-run` だけである。全件の書き込みへ切り替えるのは、Task 8 の確認が終わったあと、人が行う。

## 認証フォルダの設定

1. `tools\settings.example.json` を `tools\settings.json` にコピーする。
2. `EC_INVENTORY_DIR` を、認証 JSON を置いているフォルダの絶対パスに書く。トークンやパスワードは書かない。
3. そのフォルダに、次の4ファイルを置く。

| ファイル名 | 用途 |
|----------|------|
| `sqlserver.json` | 販売管理 |
| `logiless_oauth.json` | ロジレス |
| `amazon_spapi.json` | Amazon |
| `chatwork.json` | Chatwork |

`settings.json` は Git に載せない。実行ユーザーとプロファイルがずれても、同じ `EC_INVENTORY_DIR` を指せば読める。

## 登録先

| 項目 | 値 |
|------|----|
| コンピューター | `MARUOKA-PC` |
| 実行ユーザー | `s.maruoka` |
| 設定ファイル | `D:\development\Pandora_StockUpdateTool\tools\settings.json` |
| 開始 | 毎日 03:00 |
| タスク名 | `ECInventoryAmazonDryRun` |

## 登録するコマンド

作業フォルダは `D:\development\Pandora_StockUpdateTool` である。タスク スケジューラの「開始」にも、このフォルダを入れる。

```
"C:\Users\y.sasaki\AppData\Local\Programs\Python\Launcher\py.exe" -3 "D:\development\Pandora_StockUpdateTool\tools\nightly_amazon.py" --dry-run
```

`--dry-run` を外さない。2026-10-20 以降のツールは、`--dry-run` を外すと全件更新になり、Amazon へ数量を送る。

`MARUOKA-PC` にログオンした `s.maruoka` で、次を1行で実行する。パスワードはコマンドに書かない。登録後、タスク スケジューラで「ユーザーがログオンしているかどうかにかかわらず実行する」を選び、実行ユーザーのパスワードを1回入力する。これで、ログオンしていなくても 03:00 に動く。

schtasks /Create /TN "ECInventoryAmazonDryRun" /TR "\"C:\Users\y.sasaki\AppData\Local\Programs\Python\Launcher\py.exe\" -3 \"D:\development\Pandora_StockUpdateTool\tools\nightly_amazon.py\" --dry-run" /SC DAILY /ST 03:00 /RU "MARUOKA-PC\s.maruoka" /RL LIMITED /F

2026-10-13 にこのコマンドで登録した時点では、パスワードを保存していないため「ユーザーがログオンしているときのみ実行する」になっている。上の選択とパスワード入力を終えるまで、ログオフ中は動かない。

## 予定時刻以外の確認

03:00 を待たず、次で1回だけ動かす。

```
schtasks /Run /TN "ECInventoryAmazonDryRun"
```

完了の見方は、終了コードと `D:\development\Pandora_StockUpdateTool\output` の新しい監査ファイルである。`--dry-run` では Amazon への更新リクエストは 0 件であり、Chatwork へも投稿しない。急減の SKU は監査で「送らない」、それ以外で数量が決まった SKU は「送る」になる。終了コード 0 は、急減があっても一覧が揃っていれば成功である。終了コード 1 は取得や一覧の失敗であり、数量は送らない。全件の書き込みは、このタスクの `--dry-run` を外すまで行わない。

## 全件書き込みへ切り替えるとき

Task 8 の読み戻しが一致するまで、このタスクのコマンドは `--dry-run` のままにする。切り替えるときは、同じタスクの引数から `--dry-run` を外す。新しいタスクは作らない。
